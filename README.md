# Google Shopping Lite API examples (retired)

> **I've retired Google Shopping Lite API, so the examples in this repo no longer work.** The repo is archived and kept for reference.
> For Google Shopping price monitoring, use my **[Google Shopping API](https://apify.com/johnvc/google-shopping-api-google-shopping-products-prices-deals?fpr=9n7kx3)** instead, and start from its example repo, [Apify-Google-Shopping-API](https://github.com/johnisanerd/Apify-Google-Shopping-API).

## Use instead

- **[Google Shopping API](https://apify.com/johnvc/google-shopping-api-google-shopping-products-prices-deals?fpr=9n7kx3)**: product listings with prices, ratings, sellers, delivery info and discount tags, plus location, price-range, sort, free-shipping and on-sale filters. Example repo: [Apify-Google-Shopping-API](https://github.com/johnisanerd/Apify-Google-Shopping-API).
- **[Walmart API](https://apify.com/johnvc/walmart-api?fpr=9n7kx3)**: Walmart product details, prices, reviews and seller offers. Example repo: [Apify-Walmart-API](https://github.com/johnisanerd/Apify-Walmart-API).
